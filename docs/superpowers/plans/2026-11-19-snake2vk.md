# Frutisnake 2 VK — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter à Frutiparc le Frutisnake réécrit de Kobbs (Frutiback) comme disque `snake2vk`, à côté de l'ancien `snake3`, sans aucun enregistrement de score et avec l'Arène hors ligne.

**Architecture:** Frutiback gagne un réglage de compilation `VITE_NO_SCORES` qui coupe tout envoi de score ; son script `build-frutiparc.mjs` compile vers `Frutiparc-ruffle/public/snake2vk/`. Frutiparc ajoute un disque light `snake2vklight` (libellé `snake2vk`) branché dans ses trois vitrines, sans aucune entrée de classement.

**Tech Stack:** Frutiback : TypeScript, Vite, Pixi, Vitest, pnpm. Frutiparc : Node/Express (`server.js`), HTML/JS sans build, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-19-snake2vk-design.md`

## Global Constraints

- Identifiant interne : `snake2vk` ; nom affiché : « Frutisnake 2 VK ».
- Jeu servi sur `/snake2vk/`, fichiers dans `public/snake2vk/`.
- Aucune requête `/api/saveScore` émise par le jeu, quel que soit le mode.
- Arène : `VITE_ARENA=1`, `VITE_ARENA_SERVER=''` (bots seulement).
- Aucune modification de l'ancien `snake3` (disque, classements, scores, `/snake3/`).
- Frutiparc : branche `claude/frutiparc-ruffle-emulation-rYBHP`. Frutiback : branche `frutiparc-integration`, ne pas commiter `packages/arena-core/.vitest/`.

## Review Focus

1. Un ancien disque `snake3` qui ouvrirait désormais snake2vk (ou l'inverse) : le libellé d'un disque choisit jaquette et jeu. → test « l'ancien Frutisnake garde ses entrées » (Task 3).
2. Un `/api/saveScore?game=snake2vk…` forgé à la main : il ne doit rien enregistrer. → test serveur (Task 3).
3. Fin de partie Challenge / Entraînement / Arène avec un compte connecté : aucun `fetch` vers `saveScore`, aucun message « classement » ou « non enregistré ». → tests Task 1.
4. Le pseudo de l'Arène reste celui du compte (la session `?sid=` reste ouverte). → test Task 1.
5. Le test `fontesSwf` qui scanne `public/` pour des `.woff` tirés de SWF : les polices du build snake2vk ne doivent pas le casser. → Task 3.
