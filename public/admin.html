🎯 Mes quizz — événements animés (à la demande)

Un quiz enchaîne plusieurs questions (intro, fenêtre de réponse, révélation + gagnant, transitions d'ambiance), suit les points et annonce un classement final. Crée tes quizz, puis lance celui que tu veux dans le salon de ton choix, quand bon te semble. Chaque quiz a son propre nom, sa récompense et son temps de réponse.

📥 Importer des quizz (JSON)
Choisis un fichier .json ou colle le JSON ci-dessous. Formats acceptés : un quiz, un tableau de quiz, ou { "quizzes": [ … ] }. Voir le format ▾ 
[
  {
    "name": "Culture générale",        // requis
    "reward": 60,                       // optionnel (kikooz, 1–10000, défaut 60)
    "windowSec": 90,                    // optionnel (temps de réponse en s, 10–600, défaut 90)
    "time": "18:30",                    // optionnel : lancement auto chaque jour à cette heure (Paris) ; absent/"" = manuel
    "questions": [                      // requis (≥ 1 question valide)
      {
        "q": "Capitale de la France ?", // requis : l'énoncé
        "a": ["Paris", "paris"],        // requis : réponses acceptées (tableau OU "a;b;c")
        "r": "Paris",                   // optionnel : réponse affichée (défaut = 1re de "a")
        "image": "drapeau_fr"           // optionnel : id d'une image de quiz déjà téléversée
      }
    ]
  }
]
Notes : la comparaison des réponses ignore accents, casse et ponctuation. Les
questions sans énoncé ou sans réponse sont ignorées. "image" doit correspondre
à une image déjà téléversée ci-dessous (sinon ignorée).
