Réinitialiser le stockage local d'un jeu

Cette page efface les SharedObject Flash que Ruffle stocke dans le localStorage de ton navigateur, par jeu. À utiliser quand ta partie locale est désynchronisée de la sauvegarde serveur (cas typique : ancienne partie corrompue qui survit en mode classique alors qu'une nouvelle session marche en navigation privée).

Les autres données du site (cookie de session, clé admin, etc.) ne sont PAS touchées.
